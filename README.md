# 🏋️ Gym Planner

Aplicativo Android desenvolvido em **Java** usando **Android Studio** com o objetivo de auxiliar usuários a organizar e acompanhar seus treinos de academia de forma simples e eficiente.

---

## 📱 Sobre o projeto

O **Gym Planner** funciona como um assistente pessoal de treinos, permitindo que o usuário:

- Crie uma conta e faça login
- Cadastre e gerencie treinos (splits)
- Adicione exercícios aos treinos
- Visualize suas rotinas de treino
- Acompanhe informações básicas do seu uso

O projeto foi desenvolvido como atividade acadêmica, aplicando conceitos fundamentais como **CRUD, SQLite e navegação com Intents** no Android.

## 🧠 Funcionalidades

✅ Cadastro e autenticação de usuários  
✅ Armazenamento local com SQLite  
✅ CRUD de treinos (splits)  
✅ Cadastro de exercícios por treino  
✅ Navegação entre telas utilizando Intents  
✅ Estrutura baseada em arquitetura em camadas
